🚶 Real-time Fall Detection
A Python script that uses MediaPipe to perform real-time fall detection from a live webcam feed. By analyzing a person's skeletal pose and the angle of their torso, it can identify a potential fall and display the status on the screen.

🚀 Getting Started
These instructions will help you set up and run the fall detection script on your local machine.

Prerequisites
You need Python 3.12 and the following libraries installed:

MediaPipe: For real-time pose estimation.

OpenCV: For video capture and display.

NumPy: For mathematical calculations related to pose angles.


🛠️ Technologies Used
Python: The core programming language.

MediaPipe: A framework by Google for building computer vision pipelines.

OpenCV: An open-source library for computer vision and machine learning.

NumPy: A fundamental package for scientific computing with Python.
